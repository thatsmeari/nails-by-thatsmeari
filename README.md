NAILS BY THATSMEARI — STARTER WEBSITE

Files:
- index.html: complete responsive one-page website starter.

NEXT STEPS:
1. Go to GitHub and create a new PUBLIC repository named nails-by-thatsmeari.
2. In the repository, choose Add file > Upload files.
3. Upload index.html from this folder and commit the changes.
4. Go to Settings > Pages.
5. Under Build and deployment, choose Deploy from a branch.
6. Choose branch main and folder /(root), then Save.
7. Wait a few minutes. GitHub Pages will show your published URL on the Pages settings screen.

BEFORE SHARING WITH CLIENTS:
- Replace sample service names/descriptions and add your actual prices and durations.
- Replace gallery placeholders with your own nail photos.
- Replace sample testimonials with genuine client reviews shared with permission.
- Replace the booking button URL with your real booking page URL.
- Replace Instagram and email placeholders with your actual contact details.
- Review the wording and location information.

This is a static website starter. Appointment management is not built into the HTML; connect a separate booking service such as Setmore using its real booking URL.
